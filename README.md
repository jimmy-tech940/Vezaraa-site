# Vezaraa - Ultra-Premium Luxury Fashion E-Commerce

A fully functional, production-ready frontend prototype for a luxury fashion e-commerce brand.

## Features

### Homepage
- Cinematic hero banner with auto-sliding
- Featured collections (Men, Women, New Arrivals, Limited Edition)
- Best sellers product grid
- Brand storytelling section
- Influencer testimonials
- New arrivals showcase
- Journal/blog section
- Newsletter signup

### Navigation
- Sticky transparent navbar with scroll effect
- Mega menu with categories and product previews
- AI-powered search overlay with suggestions
- Wishlist & Cart icons with counters
- User account modal
- Dark/Light mode toggle
- Mobile responsive menu

### Product Pages
- High-resolution image gallery with zoom
- 360° view toggle
- Color variant selector
- Size selector with availability
- Add to Cart & Buy Now
- Product details tabs (Description, Details, Reviews)
- Recommended products

### Cart System
- Slide-in cart drawer
- Add/remove/update quantities
- Coupon code system (VEZARA20, LUXURY15, WELCOME10, VIP25)
- Price calculations

### Checkout
- Multi-step checkout (Shipping, Payment, Review)
- Shipping method selection
- Payment method selection (Card, UPI, PayPal, Apple Pay)
- Order summary sidebar
- Order placement simulation

### User Account
- Login/Signup modal
- Dashboard with stats
- Order history
- Wishlist page

### Content Pages
- About Us
- Blog/Journal
- Contact with form
- FAQ accordion
- Returns & Refunds policy

### Premium Features
- Dark/Light mode
- GSAP scroll animations
- Glassmorphism effects
- Micro-interactions
- Responsive design
- Toast notifications

## Tech Stack
- Vanilla JavaScript (ES6+ Modules)
- Tailwind CSS (CDN)
- GSAP + ScrollTrigger
- Lucide Icons
- LocalStorage for state persistence

## How to Run
Simply open `index.html` in a modern web browser. No build step required!
